About Phy-Hub

Here I have put together lists of high-quality external resources that I personally believe are worth learning from. They are sorted by topic, as shown in the table of contents. At the moment some are very basic/simple lists which will be updated with time.

In some places where I have yet to look into book, video and site resources, I have used some wikipedia pages as placeholders. These can be a good starting point for getting the overview of the topic's concepts, or pointing you in the direction of what subtopics you can look into for a deeper understanding. Just make sure not to go down a wikipedia rabbit hole.

Most of the resources here were picked due to them being very visual, or due to the topic being explained plainly and without being too abstract. If you have some high quality/useful resources you would like to suggest, please let me know by clicking the suggestion button in the bottom right corner, or in the contents menu if you are on your phone.

Coding and LaTeX

  • code.visualstudio.com/docs/introvideos/basics

  • brilliant.org/topics/coding/

Python

Python is a great coding language for scientific and mathematical programming as well as general purpose programming, it has a large user base and set of libraries for science and math.

  • Beginner Python Programming All-in-One Tutorial Series - by Caleb Curry
  • w3schools.com/python
  • python.org/about/gettingstarted/

LaTeX

LaTeX is a word processor used in physics and math to write notes, papers, books and more. It is used because it is easier to write math and also reformat documents (once you have learned the basics that is).

The easiest way to start LaTeX is by using the Overleaf website, but once you get on to longer or more complex documents I recommend downloading MikTeX and the VS Code extension (LaTeX Workshop)

  • overleaf.com/
  • overleaf.com/learn/latex/Learn_LaTeX_in_30_minutes
  • learn.overleaf.com/path/novice-learning-path
  • www.tug.org/texlive/
  • marketplace.visualstudio.com/items?itemName=James-Yu.latex-workshop

Symbolic Computation

Mathematica is a powerful language if you are looking to perform symbolic computations (i.e. solving differential and integral equations exactly to get a formula as the output instead of just approximate numerical values). This is incredibly helpful for solving difficult math problems, but unfortunately, Mathematica is not free.

However there are two free alternatives, which are WolframAlpha, which can be used for simple and less computationally intensive derivations, and Python's SymPy Library which can perform most of what you can with Mathematica.

  • wolframalpha.com
  • wolfram.com/mathematica
  • datacamp.com/tutorial/sympy
  • acme.byu.edu/00000179-d4cb-d26e-a37b-fffb577c0001/sympy-pdf
